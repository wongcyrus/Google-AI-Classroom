Privacy Policy

Google AI Classroom Assistant

Last Updated: September 2026

Core Commitment: The Google AI Classroom Assistant is an educational pairing tool engineered to respect student privacy and intellectual property. We do not sell user data, track personal browsing habits, or retain unauthorized personal media.

1. Information We Collect

When used in an authorized educational setting, the system processes:

  • Authentication Information: School email addresses and user roles (Teacher, Student, Admin) via Firebase Authentication and Google Identity Services.
  • Classroom Media & Telemetry: Audio streams, webcam frames, and screen captures initiated during an active, proctored classroom session for real-time transcription and lab proctoring.
  • Lecture Recordings: Audio/video streams captured during teacher-initiated lectures for automated note generation, transcription, and archiving.

2. Google Drive Integration & Scopes

The Application includes an optional Google Drive integration for instructors to backup their lecture recordings:

  • Requested Scope: https://www.googleapis.com/auth/drive.file (Per-File / Non-Broad Access).
  • Limited Purpose: This scope allows the application to upload only the video files created directly by the classroom session into the instructor's Google Drive.
  • No Access to Personal Files: The application cannot view, edit, read, or delete any other files, folders, documents, or photos in the user's Google Drive.
  • Token Retention: Temporary OAuth access tokens are stored only in the instructor's active browser session storage and are never persisted to external tracking servers.

3. Edge & On-Device Processing

Whenever supported by the user's browser, artificial intelligence processing (including Whisper speech-to-text, Gemma text assessment, and MediaPipe face landmark detection) runs locally on the user's hardware via WebAssembly/WebGPU (LiteRT). Raw intermediate camera frames are not uploaded to cloud storage when evaluated on-device.

4. Data Sharing & Security

User records, transcripts, and attendance logs are secured using Google Cloud and Firebase enterprise-grade infrastructure with strict Firestore and Cloud Storage security rules. Data is never shared with third-party advertising networks.

5. Contact & Inquiries

For questions or data access requests regarding this Privacy Policy, please contact the institution system administrator or refer to your institutional course coordinator.
